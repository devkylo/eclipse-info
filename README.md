# 이클립스: 더 어웨이크닝 · 보스 출현 타이머

MMORPG **《이클립스: 더 어웨이크닝》**의 서버별 보스 출현 예상 시간을 계산하고, 출현 전 알림과 이미지 시간표 공유를 지원하는 웹 도구입니다.
빌드 과정 없는 순수 정적 웹 구조(HTML/CSS/ES Module)로 **GitHub + Netlify(`app.netlify.com`)**에 바로 배포할 수 있으며, 로컬 PC에서는 `start.bat`으로 실행할 수 있습니다.

- **세라하 01 ~ 06**
- **발키리아 01 ~ 06**
- **바르카디온 01 ~ 06** *(현재 테스트용으로 `바르카디온 05` 기본 5종 보스 프리셋 포함)*
- **발제라 01 ~ 06**
- **셀린 01 ~ 06**

### 서버 탭 / 즐겨찾기 / 기본 접속 서버
- 최초 접속 시 **접속할 서버 선택 창**이 나타나며, 선택한 서버가 이후 접속 시 **기본 서버**로 자동 열립니다.
- 메인 화면 탭 바에는 사용자가 선택한 서버만 표시되어 화면이 깔끔하게 유지됩니다.
- **★ 즐겨찾기**: 별표를 클릭하면 즐겨찾기 서버가 탭 앞쪽에 우선 배치됩니다.
- **◀ / ▶ 탭 이동**: 같은 우선순위 그룹 내에서 탭 순서를 직접 바꿀 수 있습니다.
- **+ 서버 선택 / 관리**: 다른 서버를 탭으로 추가해 서버별 독립 시간표를 관리할 수 있습니다.

## Netlify(`app.netlify.com`) 배포 방법 (GitHub 연동)

프로젝트 루트에 [netlify.toml](./netlify.toml) (`publish = "."`)이 설정되어 있습니다.

1. 이 폴더 내용을 GitHub 저장소에 push 합니다.
2. [app.netlify.com](https://app.netlify.com/)에서 **Add new site → Import an existing project → GitHub** 선택 후 저장소를 연결합니다.
3. 설정 확인:
   - **Build command**: *(비워둠)*
   - **Publish directory**: `.`
4. **Deploy site**를 누르면 바로 배포됩니다. 정적 호스팅 환경에서는 각 사용자의 브라우저 `localStorage`에 서버별 데이터가 자동 저장됩니다.

## 로컬 실행 방법

```powershell
node server.js --open
```
또는 폴더 내 `start.bat`을 더블클릭하면 `http://127.0.0.1:3737`에서 실행되며 로컬 `data/bosses.json`에도 함께 저장됩니다.
